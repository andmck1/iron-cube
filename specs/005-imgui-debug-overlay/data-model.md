# Data Model: ImGui Debug Overlay

## Entities

### TriangleTransform

Represents the visual transform applied to the triangle in screen space.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `position` | `glm::vec2` | `{0.0f, 0.0f}` | Offset from center in normalized device coordinates (-1 to 1) |
| `rotation` | `float` | `0.0f` | Rotation angle in degrees, clockwise |
| `scale` | `float` | `1.0f` | Uniform scale factor (0.1 to 10.0 valid range) |

**Validation rules**:
- `scale` must be >= 0.1 (prevents triangle from disappearing)
- `scale` must be <= 10.0 (prevents extreme overflow)
- `position` components clamp to [-5.0, 5.0] (prevents triangle from moving off-screen entirely)
- `rotation` is unbounded (360° wraps naturally)

**State transitions**:
- Default → Modified: Debug layer writes new values via `IScene::setTriangleTransform()`
- Modified → Default: Reset button restores all fields to default values
- Modified → Applied: Vulkan renderer reads updated transform on next frame

### FpsMetric

Represents the computed frames-per-second value displayed by the debug overlay.

| Field | Type | Description |
|-------|------|-------------|
| `current` | `float` | Rolling average FPS over last 62 frames |
| `frameTime` | `float` | Time of most recent frame in milliseconds |

**Validation rules**:
- `current` is always positive (at least 1.0 fps)
- `frameTime` is always positive

**State transitions**:
- Updated each frame by Application's timing logic
- Passed to debug layer for display

### Layer

Represents a renderable component in the layer stack.

| Field | Type | Description |
|-------|------|-------------|
| `name` | `std::string` | Human-readable layer identifier |
| `order` | `int` | Render order (lower = earlier) |

**Lifecycle**:
- Created during Application initialization
- `initialize()` called once before render loop
- `render()` called each frame in stack order
- `shutdown()` called during Application teardown

**State transitions**:
- Created → Initialized: `initialize()` completes
- Initialized → Active: `render()` called each frame
- Active → Shutdown: `shutdown()` called on exit

## Relationships

```
Application
  └── manages Layer Stack (ordered vector)
        ├── SceneLayer (order 0)
        │     └── renders via IRenderer
        └── DebugLayer (order 1)
              ├── reads TriangleTransform from IScene
              ├── writes TriangleTransform to IScene
              ├── reads FpsMetric from Application
              └── renders via ImGui (VulkanRenderer executes draw commands post-layer)
```

## Data Flow

1. **Frame start**: Application measures frame delta time, updates FPS rolling average
2. **Layer iteration (SceneLayer)**: VulkanRenderer reads triangle vertices + transform from IScene, records draw commands
3. **Layer iteration (DebugLayer)**: Reads current transform from IScene, populates ImGui controls, reads FPS from Application
4. **ImGui render**: VulkanRenderer calls `renderImGui()` to execute ImGui draw commands generated by DebugLayer
5. **Frame end**: Swap buffers, present to screen
