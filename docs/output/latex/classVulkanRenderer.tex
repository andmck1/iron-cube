\doxysubsection{Detailed Description}
Vulkan renderer backend. 

Manages full Vulkan pipeline:\+ instance creation, surface, GPU selection, swap chain, render pass, graphics pipeline, descriptor sets, command buffers, and frame rendering with validation layer support.
