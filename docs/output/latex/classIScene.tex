\doxysubsection{Detailed Description}
\doxylink{classScene}{Scene} service interface. 

Abstracts scene data generation and management. Clients request scene data from the locator rather than constructing scene objects directly.

\begin{DoxyParagraph}{Thread safety}
All methods must be called from the main thread. 
\end{DoxyParagraph}
