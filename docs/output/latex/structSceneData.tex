\doxysubsection{Detailed Description}
Data-\/oriented container for renderable geometry. 

Stores vertex data contiguously in a std::\+vector for cache efficiency. Maintains a cached vertex count to avoid .size() calls in render hot path. Tracks dirty flag for incremental buffer updates.
