\doxysubsection{Detailed Description}
Platform service interface. 

Abstracts OS-\/specific window management and event handling. Implementations handle GLFW/\+\+SDL/\+etc. initialization, window lifecycle, and input routing.

\begin{DoxyParagraph}{Thread safety}
All methods must be called from the main thread. 
\end{DoxyParagraph}
