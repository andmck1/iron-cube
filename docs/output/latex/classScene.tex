\doxysubsection{Detailed Description}
\doxylink{classScene}{Scene} implementation that generates a centered, upward-\/pointing triangle. 

Stores vertex data in \doxylink{structSceneData}{Scene\+Data} struct for cache-\/friendly access. Implements \doxylink{classIScene}{IScene} interface for service locator registration.
