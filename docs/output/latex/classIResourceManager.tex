\doxysubsection{Detailed Description}
Resource Manager interface. 

Manages GPU buffer allocations and memory, providing centralized resource tracking for proper cleanup.

\begin{DoxyParagraph}{Thread Safety}
Not thread-\/safe. All calls should be made from the main thread during initialization and shutdown.
\end{DoxyParagraph}
