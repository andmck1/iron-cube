Detailed Description

Global service registry.

Stores service instances keyed by their interface type. Uses a singleton pattern for simple access throughout the application.

Thread safety
Not thread-safe. Intended for single-threaded use during application startup and shutdown.
Example
auto &locator = ServiceLocator::instance();
locator.registerService<IPlatform>(&platform);
IPlatform *p = locator.get<IPlatform>();
